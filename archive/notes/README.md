# Early working notes (archived)

These are my raw notes from the first weeks of the project: task breakdowns, rough pipeline sketches and early framing. I keep them so that the history of the project's ideas stays traceable. They aren't finished writing, and some of them are wrong. For example, `task-1b-analyzing.txt` gets the EBM evidence hierarchy backwards: conventional EBM ranks RCTs and other difference-making evidence *above* mechanistic reasoning, and the EBM+ critique is that it under-weights mechanism. The current, corrected statements are in `paper/`.

Two files have a `-v1` sibling that genuinely differs from the main version (`task-1ca-outline` and `introduction-notes`), and I kept both versions on purpose.
